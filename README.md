A simple mod that adds items from addons to TerraFirmaCraft collection advancements and fixes bugs in existing (such as sulfur duplication in "Mineralogist" or missing melon in "Healthy Diet").

| Before                           | After                          |
| -------------------------------- | ------------------------------ |
| ![Before](public/img/before.png) | ![After](public/img/after.png) |

Improved collection advancements:

- Adventuring Time
- Arborist
- Gemologist
- Gone Fishing
- Healthy Diet
- Metallurgist
- Minerologist
- True Farmer

Tested with mods:

- ArborFirmaCraft
- Beneath
- Farmer's Delight TFC
- FirmaLife
- TFC Ore Washing
