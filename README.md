A simple mod that adds items from addons to TerraFirmaCraft collection advancements.

| Before                           | After                          |
| -------------------------------- | ------------------------------ |
| ![Before](public/img/before.png) | ![After](public/img/after.png) |

Improved collection advancements:

- Adventuring Time
- Arborist
- Gemologist
- Gone Fishing
- Healthy Diet
- Metallurgist
- Minerologist
- True Farmer

Tested with mods:

- ArborFirmaCraft
- Beneath
- Farmer's Delight TFC
- FirmaLife
