# TFC Collection Advancements 🏆

### When "Every" Finally Means Every

**TerraFirmaCraft** collection advancements, rebuilt for the pack you actually play. 🌾

You added ArborFirmaCraft. Firmalife. Beneath. A dozen more. New trees. New wines. New biomes. New metals. The world got richer - the way a TFC world should.

Then you opened the advancements tab.

**Arborist** still wants the same handful of saplings. **Healthy Diet** never heard of melon. **Mineralogist** counts sulfur twice. The word _every_ - every wood, every food, every biome - describes a smaller world than the one you live in.

**TFC Collection Advancements** makes _every_ mean every. ✨

Collection advancements rebuild themselves from whatever TerraFirmaCraft and your addons actually loaded. New trees join Arborist. New foods join the diet. New biomes join Adventuring Time. Automatically. The checklist grows with the pack.

And then it gives you the collections TFC never wrote.

### What This Mod Does

This mod does not change how TFC plays. It changes what _finished_ means. 🗺️

Vanilla TFC collection advancements are patched to include addon content and to drop the bugs that made a 100% run feel dishonest. On top of that, a new set of collection advancements covers the parts of the world TFC left off the list: soils, sands, wines, jams, animals, architecture, and more.

Whatever you add to the pack, the lists update. No datapack. No hardcoded item IDs that go stale the moment you install one more addon.

#### 🧭 Key Experiences:

- **An Honest 100%:** Arborist, True Farmer, Metallurgist, Adventuring Time, and the rest finally count the world you installed - not the world TFC shipped alone. 🌳
- **The Lists TFC Forgot:** Seal every jam. Drink every wine. Tame every animal. Find every soil, every sand, every coral. Two dozen new reasons to keep walking. 🍷
- **A Checklist That Grows:** Add ArborFirmaCraft, Firmalife, Beneath, or anything else. The advancements notice. 📦
- **Bugs, Buried:** No more duplicate sulfur. No more missing melon. Deduplicated, complete, done right. 🔧

**The core TFC experience is unchanged.** I just make the completionist layer tell the truth about your world.

### ⚙️ What Gets Tracked

<details>
<summary><b>Patched TFC Collections 🛠️</b></summary>

These vanilla TFC advancements are rebuilt at load time from registries and tags, including addon content:

- **Adventuring Time** — every non-vanilla biome; Nether biomes when Beneath is loaded
- **Arborist** — every timber sapling
- **Gemologist** — every gem piece
- **Gone Fishing** — every raw fish
- **Healthy Diet** — every fruit
- **Metallurgist** — every metal you can melt into an ingot
- **Minerologist** — every unique drop from prospectable non-metal ores
- **True Farmer** — every crop, including Firmalife grapes and Beneath farmland crops

</details>

</details>

<details>
<summary><b>How It Works 🔍</b></summary>

When the server loads advancements, this mod throws out the frozen item lists and rebuilds each collection from what is actually registered: items, tags, biomes, fluids, entities.

- Addon namespaces are included automatically. Vanilla Minecraft entries are ignored, so the lists stay TFC.
- Duplicate criteria are merged - this is why Mineralogist no longer asks for sulfur twice.
- Custom triggers cover things vanilla advancements cannot: drinking a fluid, sealing a jar, familiarizing an animal, breeding from the last player who fed it.
- No new blocks, items, or mobs. The world plays the same. The scoreboard tells the truth.

</details>
